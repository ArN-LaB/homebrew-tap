# ArN-Ld Homebrew Tap

Homebrew tap for macOS apps by [ArN-Ld](https://github.com/ArN-Ld).

## Install

```bash
brew tap ArN-Ld/tap
```

## Apps

### Zenith

> Menu bar app to rank Mullvad VPN servers by latency and speed.

```bash
brew install --cask zenith
```

Requires [Mullvad VPN](https://mullvad.net) installed and logged in.

Source: [github.com/ArN-Ld/Zenith](https://github.com/ArN-Ld/Zenith)

---

## Update a cask

```bash
brew upgrade --cask zenith
```
